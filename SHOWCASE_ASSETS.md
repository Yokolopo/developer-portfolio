# Authentic Screenshots & Demonstrations

This portfolio deliberately does not contain fabricated screenshots or visual mockups presented as real software.

## Asset checklist

- [ ] **YOXON CV Studio:** capture a public product view from https://yoxon.co (remove account or customer information)
- [ ] **YOXON DEV website:** capture the live homepage at https://yoxondevllc.tech
- [ ] **YOXON Scanner:** capture a representative Android emulator screen using dummy documents
- [ ] **Morocco Mode:** capture a Flutter emulator frame from the working interface
- [ ] **Carnet Hanoty:** capture a screen with synthetic customer names and amounts
- [ ] **ViberCodify:** capture a non-sensitive development or demo screen without tokens or private customer/project data

## Safe publishing rules

1. Capture the **actual running app**, not a concept rendering.
2. Remove tokens, emails, API keys, customer names, hidden URLs and other sensitive information.
3. Confirm screenshots do not reveal private repository paths or unrelated desktop windows.
4. Export images to `assets/<project>-screenshot.png` and label each with the project, date and whether it is a prototype.
5. Add a screenshot to its case study **only after review**.

## Optional demo video

A 30–60 second silent screen recording showing one real user task is enough for an initial recruiter portfolio. Use synthetic data. Keep project stage visible.

No proprietary source code needs to be published.
